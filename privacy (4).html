Политика конфиденциальности

Дата вступления в силу: 23 сентября 2026 года.

Этот документ описывает обработку данных в Void Node на основании текущей архитектуры сервиса. Если фактическая архитектура изменится, политика должна быть обновлена.

1. Кто обрабатывает данные

Оператор: Четвериков Никита Витальевич, физическое лицо, Российская Федерация. Контакт: VoidNodeBot@gmail.com. Telegram для связи: @clofeLEAN.

2. Какие данные обрабатываются

  • Telegram: chat ID, язык, выбранный режим Beginner/Experienced, настройки, часовой пояс и состояние использования сервиса.
  • Портфель: активы, балансы, цены, стоимость портфеля, распределение, Risk Score, факторы риска и история анализов.
  • История: сохранённые результаты анализов и портфельные снимки; в текущей реализации объём истории ограничивается техническими лимитами.
  • Биржевые данные: при подключении read-only API сервис получает необходимые для анализа данные через поддерживаемую биржу. В текущей реализации поддерживаются Binance, Bybit, Gate и Kraken.
  • API-учётные данные: API key и secret key хранятся в зашифрованном виде в Redis; сообщение пользователя с исходными реквизитами удаляется после получения.
  • Торговая история: если биржа предоставляет её через read-only API, сервис может получать недавние сделки для аналитики и Portfolio DNA.
  • Подписка и платежи: тариф, даты активации/окончания, данные инвойса и связанные технические идентификаторы.
  • Реферальная программа: реферальный код, факт приглашения и начисленные бонусы.
  • AI-контекст: для формирования ответа могут передаваться портфель, Risk Score, недавние действия, новости и релевантная история диалога.
  • Anti-scam: результаты и технические факты проведённых проверок.

3. Для чего используются данные

Для авторизации и работы Telegram-бота, подключения read-only портфеля, расчёта Risk Score, формирования аналитики, anti-scam проверок, новостей, календаря, AI-объяснений, уведомлений, подписок, платежей, реферальной программы, истории и поддержки.

4. Сторонние сервисы

В архитектуре используются Telegram Bot API, Upstash Redis, Render, ccxt, Binance, Bybit, Gate, Kraken, OpenRouter, CryptoBot/Crypto Pay API, CoinGecko, NewsAPI, Finnhub, Etherscan и DexScreener. Данные передаются конкретному сервису только в объёме, необходимом для соответствующей функции.

5. Хранение

Основное состояние сервиса хранится в Upstash Redis. Redis используется как хранилище состояния; отдельные ключи имеют собственные технические ограничения и сроки жизни, поэтому нельзя считать, что все данные автоматически удаляются через один общий срок. Сервис размещён на Render; текущий регион backend-деплоя — Ohio, USA. Redis использует Upstash Global.

6. AI

AI используется как слой объяснения и контекста, а не как торговый исполнитель. Запросы к AI могут включать релевантные данные портфеля и историю, необходимую для ответа. AI-ответ не является гарантированно точным прогнозом.

7. Безопасность

Биржевое подключение должно использовать права только для чтения. Void Node не предназначен для создания ордеров или вывода средств. API-реквизиты шифруются перед сохранением. Однако ни один интернет-сервис не может гарантировать абсолютную безопасность.

8. Международная передача

Void Node доступен пользователям по всему миру, поэтому данные могут обрабатываться инфраструктурой и поставщиками в разных странах. В частности, backend размещён в США (Ohio), а Upstash Global может использовать несколько регионов. Пользователь должен учитывать это до передачи данных сервису.

9. Сроки хранения и удаление

Часть данных имеет технические TTL/лимиты, а часть пользовательского состояния может сохраняться до удаления или изменения соответствующих ключей. По запросу на удаление и в пределах применимого законодательства оператор может удалить доступные данные пользователя из используемой инфраструктуры, за исключением случаев, когда сохранение требуется законом или необходимо для разрешения споров/безопасности.

10. Права пользователя

В зависимости от применимого законодательства пользователь может иметь права на доступ, исправление, удаление, ограничение обработки, переносимость данных, возражение и иные права. Запросы направляйте на VoidNodeBot@gmail.com.

11. Возраст

Сервис предназначен для лиц от 16 лет. Если применимое право устанавливает другой минимальный возраст или требует согласия законного представителя, применяется такое право.

12. Cookies и сайт

Эта статическая версия сайта не использует собственную рекламную cookie-систему. Внешние сервисы, на которые ведут ссылки, могут обрабатывать данные по своим политикам.

13. Изменения

Политика может обновляться при изменении сервиса, инфраструктуры или требований законодательства. Новая версия публикуется на этой странице с новой датой.
