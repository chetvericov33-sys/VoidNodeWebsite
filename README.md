# Void Node Website

Static bilingual RU/EN presentation website for Void Node.

## Structure
- `ru/` Russian site + legal pages
- `en/` English site + legal pages
- `assets/` shared CSS/JS
- `404.html` fallback page

## Render
This is a Static Site. Render static sites are served through a global CDN, so the Ohio region of the Void Node backend does not apply to the website. Connect the GitHub repo and publish the repository root.

Build command: leave empty
Publish directory: `.`
